# Phase 8 – Project Demonstration

## Demo Video Script

### 1. Introduction
“Hello everyone. Our project title is PocketSmart AI – Smart Budget and Recommendation Assistant.”

### 2. Purpose
“The purpose of this project is to help users record expenses, understand their spending pattern and compare spending with a monthly budget.”

### 3. Technologies
“We developed this project using Python, Flask, HTML, CSS and MongoDB.”

### 4. Working
“First, I enter an expense name, amount and category. When I click Add Expense, the record is stored in MongoDB. The dashboard calculates total spending and remaining budget. It also displays category-wise spending and a smart recommendation.”

### 5. Benefits
“This application makes expense tracking simple and gives users quick awareness of their spending.”

### 6. Final Output
“Here we can see the dashboard, expense history, category summary and recommendation. This is the final output of our project.”
