# Phase 5 – Project Development

## Implementation
The application is implemented using Flask and MongoDB.

## Core Modules
- Dashboard
- Add expense
- Delete expense
- Category summary
- Budget calculation
- Recommendation engine

## Run Commands
```bash
pip install -r requirements.txt
python app.py
```

## Expected Local URL
http://127.0.0.1:5000

- app.py
- templates/index.html
