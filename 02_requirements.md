# Phase 2 – Requirement Analysis

## Functional Requirements
1. User can add an expense.
2. Expense contains name, amount and category.
3. Expense is stored in MongoDB.
4. User can view total spending.
5. User can compare spending with a budget.
6. User can see category-wise totals.
7. User can delete an expense.
8. System displays a recommendation.

## Non-Functional Requirements
- Simple user interface
- Fast response for normal local use
- Readable code
- Maintainable folder structure
- Basic input validation

## Hardware
- Laptop/desktop
- 4 GB RAM or above recommended

## Software
- Python 3.10+
- MongoDB
- Web browser
- VS Code or another code editor
- Git/GitHub
